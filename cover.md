*Build a query engine to learn what a query costs.*

A book for data engineers who run queries every day and want to know what they cost.
Follow the steps of a query and compare what the teaching engine counts with what DuckDB
reports. The book prepares the plans and results. Read them without running code, or open an
experiment to test a prediction in your browser. The optional building path uses Python.

[Start with the preface](#preface) to choose how to work through the book.

![A plan of three operators, scan, filter and project, with rows flowing up between them, and for each operator a prediction, an estimate and a measurement drawn as bars.](public/cover-hero.svg)
