# The fixtures

Every dataset in the book is generated by `fixtures/generate.py` from a fixed seed and written
by pyarrow, a production Parquet writer. Each exists to show one property: an order, a skew, a
number of distinct values. The same commit writes the same bytes everywhere, and the build fails
if a committed file differs from what the generator writes.

```{include} ../chapters/_generated/fixtures.md
```

Each file has a manifest beside it (`fixtures/<name>.json`) holding what pyarrow and DuckDB
report about it: its row groups and their statistics, the distinct and null counts of each
column, and the properties the generator promises. Tests check the files against the manifests
and the promises.
